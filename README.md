# ddd
Inclusao de endpoint de venda de produto:
recebe o código do produto e a quantidade desejada. Retorna o custo da venda e dá baixa no estoque ou retorna o custo igual a -1 indicando que a venda não foi possível por falta de estoque. Para o cálculo do custo final considere 10% de desconto para quantidades maiores que 10 unidades e 5% de imposto sobre o valor final
